# docs — หลักฐาน Checkpoint

โฟลเดอร์นี้ไว้เก็บภาพหน้าจอที่ GitHub มองไม่เห็นในโค้ด เช่น หน้า Firebase Console

## ภาพที่ควรมีตามใบงานที่ 1

- Checkpoint 1: หน้า repo บน GitHub (README มีชื่อคุณ + commit ในชื่อคุณ) และเว็บที่เปิดในเบราว์เซอร์
- Checkpoint 2: กระดาษที่วาดโครงสร้างข้อมูลด้วยมือ
- Checkpoint 3: หน้า Firebase Console ที่เห็นใบลา 5 ใบ
- Checkpoint 4: หน้าเว็บ (`leave-requests.html`) คู่กับหน้า Firebase Console หลังแก้ข้อมูล

วางไฟล์ภาพ (`.png` / `.jpg`) ไว้ในโฟลเดอร์นี้ได้เลย ตั้งชื่อไฟล์ให้รู้ว่าเป็นภาพของ Checkpoint ไหน เช่น `checkpoint-3-firestore.png`
